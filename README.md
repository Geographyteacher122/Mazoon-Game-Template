# قالب لعبة «مَزُون» التعليمية

لعبة منصّات تعليمية عُمانية الطابع: تركض الشخصية وتقفز وتصطدم بكتل «؟» فتظهر الأسئلة، وتنتهي الرحلة ببوابة السؤال الأخير. تعمل على الهاتف والآيباد والحاسوب، وتُستخدم في أي مادة.

**تصميم وإعداد: أ. عهود العبرية - مدرسة وادي غول للتعليم الأساسي (١-٩)**

## طريقة الاستخدام
1. حمّلي الملف `index.html` (ملف إعدادات صغير) وافتحيه بأي محرر نصوص.
2. عدّلي كتلة `window.MAZOON_SETTINGS` فقط: الاسم والشعار والمادة والألوان والأسئلة. لا تعدّلي سطر تحميل `loader.js`، فهو الذي يجلب تصميم اللعبة (`engine.html`).
3. احفظيه باسم `index.html` وارفعيه على GitHub Pages، أو استعملي البرومت الجاهز في ملف `prompt.txt` ليجهّز لك Claude النسخة.

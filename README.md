# منشئ ألعاب «مَزُون» التعليمية

أداة جاهزة: تملأ المعلمة استمارة (اسم اللعبة، الألوان، الأسئلة) وتضغط «تحميل اللعبة»، فتنزل لها لعبة كاملة في ملف واحد `index.html`. تعمل بدون إنترنت.

**تصميم وإعداد: أ. عهود العبرية - مدرسة وادي غول للتعليم الأساسي (١-٩)**

## الاستخدام
1. افتحي `index.html` (هذه الأداة) في المتصفح.
2. اكتبي بيانات لعبتك واختاري الألوان وأضيفي الأسئلة (اختيار من متعدد، أو صح وخطأ، مع صورة اختيارية).
3. اضغطي «معاينة اللعبة» لتجربتها، ثم «تحميل اللعبة».
4. لنشر اللعبة على الآيباد والهاتف ارفعي الملف الناتج على GitHub Pages أو أي استضافة.

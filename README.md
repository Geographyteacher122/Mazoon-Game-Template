# قالب لعبة «مَزُون» التعليمية

لعبة منصّات تعليمية عُمانية الطابع: تركض الشخصية وتقفز وتصطدم بكتل «؟» فتظهر الأسئلة، وتنتهي الرحلة ببوابة السؤال الأخير. تعمل على الهاتف والآيباد والحاسوب، **وتعمل بدون إنترنت**.

**تصميم وإعداد: أ. عهود العبرية - مدرسة وادي غول للتعليم الأساسي (١-٩)**

## الملفات (ضعيها كلها في مجلد واحد)
- `settings.js` ← **الملف الوحيد الذي تعدّلينه** (الاسم والشعار والمادة والألوان والأسئلة).
- `index.html` و`engine.js` و`assets.js` ← تصميم اللعبة، لا تعدّليها.

## طريقة الاستخدام
1. حمّلي الملفات الأربعة في مجلد واحد.
2. عدّلي `settings.js` بنفسك، أو أرسليه إلى أي برنامج ذكاء اصطناعي مع البرومت الموجود في `prompt.txt`، ثم استبدلي الملف بالنسخة الجديدة.
3. افتحي `index.html` لتجربة اللعبة. ولنشرها ارفعي الملفات الأربعة على GitHub Pages أو أي استضافة.

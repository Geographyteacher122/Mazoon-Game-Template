# منشئ الألعاب التعليمية

أداة جاهزة: يملأ المعلم أو المعلمة استمارة (اسم اللعبة، الشخصية، الألوان، الأسئلة) ويضغط «تحميل اللعبة»، فتنزل له لعبة كاملة في ملف واحد `index.html`. والشخصية للاختيار: «مَزُون» أو «سلطان». اللعبة الناتجة تعمل بدون إنترنت.

**تصميم وإعداد: أ. عهود العبرية - مدرسة وادي غول للتعليم الأساسي (١-٩)**

## الاستخدام
1. افتح `index.html` (هذه الأداة) في المتصفح.
2. اكتب بيانات لعبتك واختر الشخصية والألوان وأضف الأسئلة (اختيار من متعدد، أو صح وخطأ، مع صورة اختيارية).
3. اضغط «معاينة اللعبة» لتجربتها، ثم «تحميل اللعبة».
4. لنشر اللعبة على الآيباد والهاتف ارفع الملف الناتج على GitHub Pages أو أي استضافة.
